## Implemented behavior

- Each fresh attempt has a distinct run ID. Transitions append stable, ordered events for authored context, questions, confirmed input, decisions/reactions, disclosure, delayed consequences, memory and completion. Prior event records are preserved when a new state is returned.
- Effects retain before, requested, actual and after values, including clamping. Bonus records distinguish eligibility from the actual marginal gain. A capped bonus with no extra gain no longer triggers the existing **Evidence mattered** display or increments the debrief's listening-improvement count.
- Public decisions contain the confirmed approach and authored reactions. Raw confirmed wording lives in a separate player-only input event. Questions remain known to their source and player; a public score does not grant knowledge.
- Rumor records distinguish an unverified interpretation from the earlier planning note. Open disclosure shares the note broadly. A private reset preserves Leah's prior knowledge but does not grant Theo access to the full note/private agreement. The ignored-rumor defect remains Ishan's knowledge in-world, with a player-visible narrator record.
- Four conditional conversation rules cover 12 branches: Mara and Ishan recall R1 in R2; Leah recalls R2 in R3; Theo recalls R4 and its actual arrival in R5. Reading or reopening these callbacks creates no event or numerical effect. Missing, contradictory or unauthorized source records suppress the callback and produce QA diagnostics.
- Advancing validates the committed predecessor records before applying a consequence or certifying completion. Rejected input leaves the caller's state unchanged. These checks are integrity guards, not a secure anti-cheat or persistence system.
