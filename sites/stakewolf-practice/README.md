# Stakewolf practice preview — SCRUM-37

Owner-review checkpoint, 2026-10-24. Implements the connected interface proposed in SCRUM-19 and GitHub PR24. This is a bounded design prototype, not a validated interview assessment product.

## Try it

Private preview: https://stakewolf-practice.v4nswe.chatgpt.site

For a local preview, run `node serve.mjs` in this directory, then open http://127.0.0.1:4184/. Requires an installed Node runtime; no packages or build step.

1. General practice → choose one of three rounds → investigate claims and records → recommend → respond to new evidence → review your trace.
2. Interview preparation → paste a JD or use a synthetic sample → confirm/change the UI or ADAS example track → inspect the preparation path → complete its practice round → review.

The two entrances share a small practice workspace, with different growth, UI and ADAS content. Werewolf-inspired elements shown here are competing incentives, incomplete claims, questioning and reconsidering decisions. Hidden-role simulation, open conversation, evolving consequences and a calibrated assessment engine are not implemented.

## Boundaries

- Local keyword matching; two prepared role profiles. No live AI or inference cost.
- User-entered text and activity remain in browser memory and clear on refresh. No account, uploads, analytics or browser storage.
- Text notes are displayed verbatim, never automatically graded. Reflection follows the selected recommendation.
- New evidence is fixed for each sample, not generated from the decision.
- Target level is a preview preference, not calibrated difficulty.
- ADAS material is illustrative and requires expert review before external assessment use.
- No DNS changes, purchases, schedules or further feature work are part of this checkpoint.

See REVIEW.md for actual checks and limitations. Stop at owner review of the visual direction and connected journeys before expanding scope. Previous November targets require reforecast for the platform pivot; this preview does not establish release readiness.
